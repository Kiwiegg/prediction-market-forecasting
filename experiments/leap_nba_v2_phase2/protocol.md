## Qualitative assessment and orientation

Use the four complete registered prompts, `xy_schema.json` for A and `home_away_schema.json` otherwise. Exactly three fields: favored_side (X/Y/neither or home/away/neither), strength (neutral/slight/moderate/strong/very_strong), evidence_sufficiency (adequate/limited/insufficient). Neither iff neutral; supported sides require nonneutral strength. Insufficient must be neither+neutral and is an **abstention with null LR**, never an accepted neutral estimate. Invalid JSON, duplicate/extra fields, invalid enums or incoherent combinations fail without repair or retry. No explanations, final probabilities, scores, tools, search, Kalshi or remembered game results.

Mapping is frozen: neutral=1, slight=1.25, moderate=1.75, strong=2.5, very_strong=4. The model does not see the numerical mapping. X support gives LR_XY=magnitude; Y gives its reciprocal. If X denotes home, LR_home=LR_XY; if X denotes away, LR_home=1/LR_XY. Other groups map home/away directly. Usable neither maps to LR_home=1. Mapped values must be positive finite; no silent clipping. These are **heuristic mapped ratios, not calibrated statistical likelihood ratios**.

## Aggregation and missingness

Retain v1's stable neutral-prior arithmetic: prior P(home)=0.5; log_odds=alpha*sum(log(LR_home)); p=sigmoid(log_odds). Prespecified variants raw alpha=1 and conservative alpha=0.5 share exactly the same group observations. No fitted hyperparameters. Legitimately absent groups have status skipped_missing, LR=1, log contribution=0 and explicit reason/state. A with zero completed games differs from unavailable statistical sources. Failed, insufficient, interrupted, access-denial-blocked or budget-blocked **required** inference makes both full forecasts missing; preserve partial observations and never substitute LR=1. Save group log-LRs, weighted contributions and leave-one-group-out probabilities using v1 arithmetic, offline only for complete forecasts.
